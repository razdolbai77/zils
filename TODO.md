## High Priority - Correctness Bugs

- [x] Track an approximate program counter for `$` in conditional assembly: `computeInactiveLines` passes `currentLoc = i` — the line index (src/asm/document.ts:129) — as `$`, so `if $ == 0xC000` needs ~49152 lines to fire and `if $` is always true after line 0. Additionally the assignment sits AFTER the conditional-directive branches `continue`, so an `if` condition evaluates `$` as the PREVIOUS active line's index (src/asm/document.ts:85 vs :129) — move `currentLoc = i` to the top of the loop body at minimum. Track a running location across data directives (`db`/`dw`/`ds` widths) and `org`/`phase`, or document the limitation next to `evaluate`'s `$` handling; test an `if` gated on `$` relative to a preceding `org`.
- [x] Create `test/signature-help.test.ts`: signature help has one integration case in advanced-lsp.test.ts:110-118, leaving `countActiveParameter`, `buildOverloadSignatureInformation`, and `buildSignatureInformation` (src/lsp/signature-help.ts) uncovered for edge cases — nested parens around the cursor position, cursor exactly at the opening `(` and at the comma, multi-overload selection, and empty operand lists.
- [x] Gate `.RANDOM(n)` out of `isConstantExpression`: the FunctionCall arm (src/asm/expressions.ts:507-508) returns true when all args are constant, so `.RANDOM(5)` passes the constant gate and `evaluate` runs `Math.random()` inside the range validators (diagnostics.ts:24-26, :522-524, :1291-1293), making directive range checks nondeterministic across publishes. Return false when the callee name equals `RANDOM_FUNCTION` (case-insensitive) and test that a `.random` operand never takes the constant fast path.
